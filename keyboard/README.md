# Раскладка клавиатуры UkrLat для macOS

Нативный бандл клавиатуры `UkrLat.bundle` для macOS на базе **US QWERTY** с диакритикой через **`Option (⌥)`** (по аналогии с *Polish Pro* / *Slovak QWERTY*) и автоматической привязкой к разделу **«Українська»** (`TISIntendedLanguage = uk`).

## Быстрая установка

### Через VS Code (кнопка Play ▶ / Tasks)
Откройте **Run and Debug (`Cmd + Shift + D`)** и выберите:
* **`⌨️ Установить раскладку UkrLat для macOS`**

### Через терминал
```sh
# Установить для текущего пользователя (~/Library/Keyboard Layouts)
bun run keyboard:install

# Установить для всех пользователей (/Library/Keyboard Layouts)
sudo bun run keyboard:install -- --system

# Только пересобрать бандл в keyboard/UkrLat.bundle
bun run keyboard:build
```

После копирования команда автоматически регистрирует бандл в macOS через `TISRegisterInputSource`:
1. Закройте (`Cmd + Q`) и заново откройте **Системные настройки → Клавиатура → Источники ввода → Изменить...** (если система всё ещё показывает кэшированный список, перелогиньтесь в macOS или перезагрузите Mac).
2. Нажмите **«+»**, выберите категорию **Українська** (*Ukrainian*) и добавьте **UkrLat**.

## Схема набора (Option `⌥` + клавиша)

Заглавные буквы вводятся с **`Option + Shift` (`⌥ + ⇧`)** или с включённым `Caps Lock`.

| Категория | Комбинации | Принцип запоминания |
|---|---|---|
| **Йотированные и Ґ** | `⌥+A`=`â` · `⌥+E`=`ê` · `⌥+I`=`î` · `⌥+U`=`û` · `⌥+G`=`ĝ` | Базовая латинская буква |
| **Шипящие (č, š, ž)** | `⌥+C`=`č` · `⌥+S`=`š` · `⌥+Z`=`ž` | Базовая латинская буква |
| **Диграф Щ (šč)** | `⌥+Q`=`šč` (`⌥+⇧+Q`=`Šč`, `⇪+⌥+Q`=`ŠČ`) | Свободная клавиша `Q` |
| **Мягкие (основные)** | `⌥+D`=`ď` · `⌥+T`=`ť` · `⌥+L`=`ĺ` · `⌥+N`=`ń` · `⌥+R`=`ŕ` | Базовая латинская буква |
| **Мягкие (ś, ź, ć)** | `⌥+W`=`ś` · `⌥+X`=`ź` · `⌥+V`=`ć` | Соседние клавиши: `W` над `S`, `X` рядом с `Z`, `V` справа от `C` |
| **Валюта и типографика** | `⌥+4`=`₴` · `⌥+⇧+4`=`€` · `⌥+'`=`’` · `⌥+[`=`«` · `⌥+]`=`»` · `⌥+-`=`–` · `⌥+⇧+-`=`—` | Гривна, укр. апостроф, ёлочки, тире |

### Альтернатива для печати одной рукой — «мёртвые клавиши» (Dead Keys)

* **Смягчение (`⌥+;`):** нажмите `⌥+;`, отпустите и нажмите `c / s / z / d / t / l / n / r` → `ć / ś / ź / ď / ť / ĺ / ń / ŕ`.
* **Гачек / циркумфлекс (`⌥+\`):** нажмите `⌥+\`, отпустите и нажмите `a / e / i / u / g / c / s / z / d / t` → `â / ê / î / û / ĝ / č / š / ž / ď / ť`.
