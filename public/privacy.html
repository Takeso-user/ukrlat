Privacy Policy (English)

Effective Date: November 19, 2026

1. Overview & Scope

This Privacy Policy describes how the UkrLat — Українська латинка browser extension (for Google Chrome, Mozilla Firefox, Apple Safari, and Chromium-based browsers) and the official web application at https://ukrlat.uk handle user data.

UkrLat is designed with privacy first: all Ukrainian-to-Latin transliteration and language detection inside the browser extension execute 100% locally on your device.

2. No Collection of Personal or Sensitive User Data

The UkrLat browser extension does not collect, harvest, store remotely, transmit, sell, or share any personally identifiable information, browsing history, visited URLs, webpage content, keystrokes, analytics, or telemetry with the developer or any third party.

  • Page transliteration and language detection happen strictly in memory inside your browser tab.
  • No text from the pages you read or the forms you fill in ever leaves your device via the extension.
  • Sensitive input fields — specifically password, email, number, date, time, file, color, and range — are explicitly excluded from live input transliteration.

3. Extension Permissions & Local Storage

To perform its single purpose (transliterating Ukrainian Cyrillic text into UkrLat Latin script), the extension requests only minimal permissions:

Permission / API Purpose & Local-Only Scope
content_scripts (<all_urls>) Runs locally inside web pages to detect whether a page is predominantly in Ukrainian and transliterate DOM text nodes, user selections (Alt+U), or eligible text inputs on demand. Page text is never transmitted off the device.
storage (chrome.storage.sync / chrome.storage.local) Stores only your extension preferences: autoPageTransliterate, liveInputTransliterate, and user-chosen per-domain overrides (siteOverrides). This data stays within your browser profile or browser sync account and cannot be accessed by the developer.
contextMenus Adds context-menu actions to transliterate selected text or toggle Latin script on the currently active tab when clicked by the user.

4. Website & REST API (https://ukrlat.uk)

When you visit the web application at https://ukrlat.uk or send a request to POST /api/v1/transliterate, any submitted text is processed purely in memory in order to compute and return the transliterated result. Submitted text is never logged to disk, retained, profiled, or shared with third parties.

The website uses browser localStorage solely to remember your chosen display script (ukrlat_page_script: Cyrillic or Latin) and does not use advertising cookies or third-party tracking scripts.

5. Third-Party Sharing & Chrome Web Store Limited Use Disclosure

We do not sell, rent, trade, or transfer any user data to third parties, data brokers, or advertising networks. The use of information received from Google APIs and browser extension APIs adheres strictly to the Chrome Web Store User Data Policy, including the Limited Use requirements.

6. User Control & Data Deletion

You remain in full control of your preferences at all times. You can disable automatic transliteration or clear per-site settings from the extension popup at any time. Uninstalling the extension immediately stops all local processing and removes all stored extension preferences from your browser.

7. Contact Information & Policy Updates

If you have any questions about this Privacy Policy or the extension's privacy practices, please contact the developer:

Політика конфіденційності (Українська)

Дата набрання чинності: 19 листопада 2026 р.

1. Загальні положення

Ця Політика конфіденційності пояснює, як браузерне розширення UkrLat — Українська латинка (для Google Chrome, Mozilla Firefox, Apple Safari та браузерів на базі Chromium) і вебплатформа https://ukrlat.uk обробляють дані користувачів.

UkrLat створено з фокусом на повну приватність: визначення мови сторінки та транслітерація української кирилиці в латинку в розширенні виконуються виключно локально у вашому браузері.

2. Відсутність збору персональних чи конфіденційних даних

Розширення UkrLat не збирає, не зберігає на сторонніх серверах, не передає, не продає та не розкриває третім особам жодних персональних даних, історії відвідувань, URL-адрес, вмісту вебсторінок, натискань клавіш або аналітики.

  • Аналіз тексту сторінок і транслітерація відбуваються виключно в оперативній пам'яті вашої вкладки браузера.
  • Жоден текст зі сторінок або форм не передається на зовнішні сервери через розширення.
  • Чутливі поля вводу — зокрема password, email, number, date, time, file, color та range — гарантовано виключені з автоматичної транслітерації при введенні.

3. Дозволи розширення та локальне сховище

Для виконання єдиного призначення (транслітерації українського тексту латинкою UkrLat) розширення використовує лише мінімально необхідні дозволи:

Дозвіл / API Призначення та локальна робота
content_scripts (<all_urls>) Працює локально на вебсторінках, щоб виявляти переважання української мови та транслітерувати текстові вузли DOM, виділений текст (Alt+U) або звичайні текстові поля за бажанням користувача. Вміст сторінок нікуди не надсилається.
storage (chrome.storage.sync / chrome.storage.local) Зберігає лише ваші власні налаштування: autoPageTransliterate, liveInputTransliterate та список винятків для окремих доменів (siteOverrides). Ці налаштування зберігаються виключно у профілі вашого браузера й недоступні розробнику.
contextMenus Додає пункти контекстного меню правої кнопки миші для транслітерації виділеного фрагмента або перемикання режиму на поточній сторінці.

4. Вебсайт і REST API (https://ukrlat.uk)

Під час використання онлайн-конвертера на сайті https://ukrlat.uk або звернення до ендпоінту POST /api/v1/transliterate надісланий текст обробляється в оперативній пам'яті виключно для повернення результату транслітерації та не записується у журнали, бази даних чи треті сервіси.

Вебсайт використовує localStorage лише для запам'ятовування вибраної графіки інтерфейсу (ukrlat_page_script: кирилиця або латинка) і не використовує рекламних cookie чи сторонніх лічильників відстеження.

5. Передача даних третім особам і вимоги Chrome Web Store (Limited Use)

Ми не продаємо, не передаємо й не розкриваємо дані користувачів третім особам чи рекламним мережам. Обробка будь-яких даних у межах API браузера повністю відповідає правилам Chrome Web Store User Data Policy, включно з вимогами обмеженого використання (Limited Use requirements).

6. Керування даними та видалення

Ви можете будь-якої миті змінити налаштування автоматичної транслітерації або скинути параметри для конкретних сайтів у меню розширення. Видалення розширення з браузера негайно припиняє всю локальну обробку та видаляє локально збережені налаштування.
