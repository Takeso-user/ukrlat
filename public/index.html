Сучасна орфографія

Підтримка стандартних діакритичних літер (č, š, ž, ľ, ń, ď, ť) для точної та безпомилкової передачі вимови.

Гарячі клавіші (Alt + U)

Виділіть будь-який абзац або коментар на сайті та натисніть комбінацію клавіш для миттєвої транслітерації.

🖱️

Контекстне меню

Зручний пункт у меню правої кнопки миші браузера дозволяє читати великі статті в латинській графіці.

🚀

Відкритий REST API

Простий та швидкий бекенд-ендпоінт для розробників ботів, мобільних додатків та сторонніх інтеграцій.

Латинська абетка UkrLat

Сучасна стандартизована латинська абетка для української мови. Впорядкована за класичним латинським стандартом (A → Z) з урахуванням діакритичних знаків.

REST API для розробників

Використовуйте публічний API UkrLat для автоматичної транслітерації у своїх проектах.

Ендпоінт: POST /api/v1/transliterate

Надішліть JSON із полем inputText, отримайте результат у полі outputText.

curl -X POST https://ukrlat.uk/api/v1/transliterate \ -H "Content-Type: application/json" \ -d '{"inputText": "Привіт, світе!"}' # Відповідь (200 OK): # {"outputText": "Pryvit, svite!"}
